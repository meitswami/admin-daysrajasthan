# AGENTS

Always:
- Think before coding.
- Follow ARCHITECTURE.md (single app, feature modules).
- Put domain logic in `src/modules/*`, not in page files.
- Intelligence never queries Supabase; use Knowledge (+ Search).
- Intelligence returns structured JSON; Renderer owns UI.
- Reuse components and design-system tokens.
- Use TypeScript.
- Validate every API.
- Create loading, error and empty states.
- Optimize Core Web Vitals.
- Keep files modular.
- Avoid duplicate code.
- Prefer extending existing tables over creating parallel ones.
